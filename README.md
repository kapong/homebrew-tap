# Kapong Tap

## How do I install these formulae?

`brew install kapong/tap/<formula>`

Or `brew tap kapong/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kapong/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
